# Posting Rules

- Main post: one natural Traditional Chinese sentence, ideally 15–35 characters.
- Main post must not contain Shopee, affiliate, commission, or raw product links.
- Each generated post selects four active products.
- Product replies use official Shopee URLs; use an official affiliate short URL when provided.
- Do not invent product claims, fake links, fake engagement, or fake publishing status.
- Prefer unused/recently-unused products and avoid repeating the same topic opening.
- Real publishing is opt-in only. The default execution path is dry-run.
- Never bypass login, CAPTCHA, MFA, device verification, or platform authorization.
