Local auto-sync

如果 THEARD 是跑在你的 Windows 電腦，可以讓它掃描 Downloads。你只需要在蝦皮官方後台按「下載」，後面的匯入、更新商品池與排名由 THEARD 接手。

A / 官方批次連結

python affiliate/import_links.py your-links.csv：把合法推廣連結、Sub ID、分潤率與商品欄位正規化到 data/products.json。

B / 官方成效報告

python affiliate/import_performance.py report.csv：回填 clicks、orders、CVR、EPC、commission 與 ranking score。

C / Downloads Bridge

python affiliate/sync_downloads.py：掃描新 CSV，自動判斷是批次連結還是成效報告，已處理檔案不會重複匯入。

D / Daily Production

同步完成後沿用 daily_production.py → publisher_pipeline.py。真實 Threads 發布仍使用原本的 guarded authorization。

# Windows / PowerShell # .env 可指定你的下載資料夾 THEARD_SHOPEE_DOWNLOADS=C:\Users\YOUR_NAME\Downloads # 手動同步一次 python affiliate/sync_downloads.py # 產生當日內容 python scripts/daily_production.py python scripts/publisher_pipeline.py # Optional: 本機 AI，不呼叫 OpenAI THEARD_LOCAL_AI=1 OLLAMA_MODEL=qwen3:4b

Guardrails

連結分潤平台不等於繞過平台。THEARD 自動化資料整理與決策，但不自動製造點擊、不碰付款流程，也不繞過帳號驗證。

BLOCK
不繞過平台驗證

不處理 CAPTCHA、MFA、裝置驗證、登入繞過或未授權私有 API。

VERIFY
只接受真實分潤連結

缺少官方推廣連結的商品不應進入真實發布，AI 也不能自行捏造 affiliate URL。

TRACE
Sub ID 做歸因

用平台、主題、活動與內容批次做 Sub ID，讓訂單可以回到真正的內容來源。

NO FAKE TRAFFIC
不自動點自己的連結

Bridge 只同步資料；不產生機器人點擊、假轉換或任何看起來像真人的虛假流量。
