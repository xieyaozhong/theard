AFFILIATE
LEARNING ENGINE.

不是把商品大量丟到社群，而是把「選品、內容、發布、成效、下一輪決策」接成一個可觀察、可回復、可逐步自動化的循環。

預設不需要 OpenAI API。內容可以維持原本 deterministic 產生器，或在本機啟用 Ollama。蝦皮資料以官方分潤後台匯出的 CSV／合法取得的分潤連結為來源，不繞過登入、驗證或平台限制。

System loop

THEARD 原本的 Topic → Content → Product → Verify → Publish 保留不動，新增 Affiliate Performance Layer，讓 Product Agent 能根據實際分潤表現調整排序，而不是只看關鍵字。

01 / INPUT

Product Pool

商品、分類、官方分潤連結、Sub ID、價格與圖片。沒有合法連結的商品不進入實際發布。

02 / DECIDE

Ranking Agent

綜合主題相關性、近期使用、CVR、EPC、分潤率與資料信心，挑出最值得測試的商品組合。

03 / CREATE

Content + Ollama

產生台灣 Threads 生活型內容。本機 Ollama 為可選模組，未啟用時回到 deterministic fallback。

04 / LEARN

Performance Loop

匯入分潤成效 CSV，更新商品 score，再回到下一輪選品。成效資料不會直接改寫發布安全閘門。

Affiliate CSV lab

這個工具完全在瀏覽器本機運算。你可以先用範例資料驗證 ranking 邏輯，再把蝦皮分潤後台匯出的欄位整理成相同格式。檔案不會上傳到 THEARD 伺服器。

Production path

建議先做到「每週補商品池 + 其餘流程自動」，而不是用瀏覽器機器人暴力登入蝦皮後台。這樣比較穩定，也比較符合平台授權邊界。

A / 更新商品池

從官方分潤工具取得合法分潤連結與 Sub ID，寫入 data/products.json。不自動猜測或偽造 affiliate URL。

B / 匯入成效

執行 python affiliate/import_performance.py report.csv，回填 clicks、orders、CVR、EPC、commission 與 ranking score。

C / 每日生成

scripts/daily_production.py 先選高相關且高品質商品，再產出 preview。設定 THEARD_LOCAL_AI=1 時可改用 Ollama。

D / Guarded publish

沿用現有 Publisher Pipeline。Preview、網址、狀態與內容檢查未通過就不發；真正發布仍需要明確授權。

Guardrails

全自動不是把所有保護機制拿掉。THEARD 的設計是：能自動的資料整理與決策盡量自動；涉及帳號權限、真假資訊、平台政策與實際發布時保留明確邊界。

BLOCK
不繞過平台驗證

不處理 CAPTCHA、MFA、裝置驗證、登入繞過或未授權的私有 API。若資料只能從後台匯出，就以人工匯出檔案作為穩定交接點。

VERIFY
不捏造商品事實

本機 AI 只負責內容表達，不自行發明折扣、價格、療效、銷量或使用心得。缺資料就不寫成確定事實。

TRACE
用 Sub ID 做歸因

把不同平台、內容主題、時段或活動編進 Sub ID，讓後續成效分析知道訂單來自哪個內容，而不是只看總營收。

HUMAN GATE
發布權限獨立

Ranking 或 AI 產文成功，不代表允許發布。THEARD 仍把 Publisher State、Dry Run 與真實 API 授權分開。
