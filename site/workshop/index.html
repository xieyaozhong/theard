// FIVE OBSERVABLE FACTOR FAMILIES
為什麼同 prompt 仍會產生不同結構？

            

              
01
模型家族與架構
不同模型家族可能採用不同設計、規模與推論方式，因此對規劃、段落組織與指令權重的表現可能不同。
觀察：篇章順序、拆解深度、長距離一致性

              
02
訓練資料與目標
資料分布、語言覆蓋、任務配方與訓練目標不同，會影響模型熟悉的文體、範例模式與知識表達。
觀察：例子類型、術語選擇、語言自然度

              
03
系統指令與對齊
產品層的系統訊息、安全規則和回應偏好可能先於使用者 prompt 生效，改變拒答、說明、格式與保守程度。
觀察：前言、警語、限制處理、是否主動澄清

              
04
上下文與工具
對話歷史、檢索內容、記憶、搜尋或其他工具若不同，即使最後一則 prompt 相同，模型實際取得的上下文仍可能不同。
觀察：引用、即時資訊、沿用前文、工具痕跡

              
05
取樣與解碼
生成通常不是固定模板輸出。溫度、top-p、隨機種子或平台預設可能讓同模型在不同執行中選到不同措辭與結構。
觀察：同工具重跑後的變異、開頭與排序差異

            

            
邊界聲明：以上是可用來提出與驗證假設的通用因素，不代表我們知道任何特定產品未公開的私有架構、資料、系統指令或取樣設定。課堂結論應以公開文件與本次可觀察輸出為準。
